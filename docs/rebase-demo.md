# Demo Rebase

Questa funzionalità viene sviluppata su un feature branch.

## Obiettivo
Comprendere il funzionamento del comando git rebase.

## Procedura

1. Creare un feature branch da main.
2. Realizzare una o più modifiche.
3. Aggiornare main con nuovi commit.
4. Eseguire il rebase del feature branch su main.
5. Verificare la nuova storia dei commit.
